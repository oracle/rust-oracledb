About rust-oracledb

The rust-oracledb driver is an open-source Rust module that enables Rust applications to connect to Oracle Database directly with no additional libraries required. This lightweight and high-performance driver gives Rust applications easy access to Oracle Database through the Oracle Net protocol. The module is maintained by Oracle.

This is a pre-release of rust-oracledb, intended to provide early access to the driver and gather user feedback. The APIs and functionalities are subject to change as development continues.

Rust-oracledb supports basic and advanced features of Oracle AI Database.

rust-oracledb Features:

  • Install from crates.io. Find the source code on GitHub

  • Pure Rust 'Thin' driver

  • SQL Execution and PL/SQL Execution

  • Batch Statement Execution and Bulk Loading

  • Edition-Based Redefinition

  • Large Objects: CLOBs, BLOBs and NCLOBs

  • Oracle Database JSON data type

  • Oracle Database VECTOR data type

  • Transaction Management

  • Connection Pooling

  • Privileged Connections

  • Password Changing

  • Statement Caching

  • End-to-end Tracing, Mid-tier Authentication, and Auditing

  • Use of Oracle Network Service infrastructure including encrypted network traffic and security features.

  • Oracle's standard cross-version interoperability allows easy upgrades and connectivity to different Oracle Database versions.

We are actively working on supporting the best Oracle Database features, and on functionality requests from users involved in the project.
